# YouTube コメント・おすすめ入れ替え拡張

YouTube の視聴ページで

* **コメント欄とおすすめ動画欄を入れ替え**
* **左右のスクロールを独立**

が可能になります

---

## 主な機能

### コメント欄 ↔ おすすめ動画をワンタップ切替

高評価ボタン等が並ぶ列に追加される「↔︎」ボタンを押すとコメントとおすすめ動画欄が入れ替わります。

### 独立スクロール

左右の行が別々にスクロールできます。これにより動画を固定したままコメントのみをスクロール可能になります

### 状態保持

入れ替え状態は自動で保存され、
YouTube の移動後も反映されます。

---

## 🔧 インストール方法（開発モード）

1. このリポジトリをダウンロード
2. Chrome の拡張ページを開く
   `chrome://extensions/`
3. **デベロッパーモード ON**
4. **パッケージ化されていない拡張機能を読み込む**
5. フォルダを選択

YouTube を開けばボタンが表示されます。
